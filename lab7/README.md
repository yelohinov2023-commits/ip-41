# Lab7 — варіант 1

Євгеній Логінов, ІП41. Навчальне відтворення блоків lpnu.ua.

- `header#events_container`: Flexbox, шість подій.
- `.news-grid`: CSS Grid, дванадцять новин.
- До 767 px — одна колонка; 768–1023 px — дві; від 1024 px — чотири в обох блоках.
- `transition` для посилань, карток і зображень; `@keyframes appear` для появи карток.
- Для `prefers-reduced-motion: reduce` рух вимкнений.
- Усі зображення збережені локально. Картки посилаються на оригінальні публікації.
- Статична сторінка без збірки: відкрити index.html або запустити локальний HTTP-сервер.

Матеріали і фотографії: https://lpnu.ua/ (стан на 10.11.2026). Це навчальна робота, не офіційний сайт університету.
