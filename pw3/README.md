## Реалізація

- Семантичні секції Home, Trivia, Categories, Scores, Subscribe, Contact.
- Зовнішній CSS, Flexbox, мобільний breakpoint 640px.
- Три локальні SVG-ілюстрації з alt, таблиця із caption та scope.
- Підписка зберігає лише налаштування у localStorage. Листи й сповіщення не надсилаються.
- Контактна форма перевіряє поля локально. Повідомлення не передаються й не зберігаються.
- Фокус клавіатури, skip-link, прихований текст, role=status, reduced-motion.
