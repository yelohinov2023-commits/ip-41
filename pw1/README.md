# Практична робота №1
## Мета
Створити багатосторінковий блог із семантичною HTML-розміткою, навігацією, галереєю та доступними формами.
## Теоретичні відомості
HTML визначає структуру документа. Семантичні блоки пояснюють призначення вмісту. CSS керує відображенням, відносні URL зв’язують сторінки, а label, alt та заголовки допомагають користувачам допоміжних технологій.
## Завдання і виконання
Створено головну сторінку, сторінки Парижа, Кіото й Лондона, галерею, контакти, підписку та службові сторінки. Наданий style.css збережено в css/style.css; адаптивність і видимий фокус додано окремо. Підключено favicon.ico 16×16. Усі сторінки мають UTF-8, lang="uk", viewport та спільне меню. Форми використовують method="post", пов’язані label та поля із required. JavaScript демонструє надсилання локально, оскільки GitHub Pages не має серверного обробника. Дані не зберігаються.
Історії — уявні подорожі відповідно до творчого вступу завдання. Фотографії не видаються за власні: кожна має джерело Wikimedia Commons у підписі.
Роботу підготовлено у гілці pw1 для об’єднання з main.
## Контрольні питання
1. Структура блогу: header, nav, main, section, article, footer.
2. Семантичні теги покращують зрозумілість, доступність, підтримку та індексацію.
3. Галерея використовує section, ul, li, figure, img і figcaption: список об’єднує фото, figure пов’язує зображення з підписом.
4. Навігація — списки посилань a з відносними адресами сторінок та якорями.
5. Форми містять form, input, textarea, label і button. Для пошти використано type="email", для згоди — checkbox.
6. Зображення мають змістовний alt; label пов’язані через for/id; поля мають required, фокус видимий, статус форми має role="status"; емодзі мають aria-label.
7. Footer містить службові й соціальні посилання, контакти та копірайт.
